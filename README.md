# Typing Speed Test

## Overview

This Typing Speed Test is a web-based application designed to help users improve their typing skills and measure their typing speed and accuracy.

## Features

### 🚀 Instant Start
- Begin the test immediately by starting to type
- No need for manual test initiation

### 📊 Live Accuracy Tracking
- Real-time monitoring of your typing performance
- Track correct word count and accuracy percentage as you type

### 🔄 Restart Option
- Easily restart the test using the same piece of text
- Perfect for practicing and improving on specific passages

### 🔀 Reset Functionality
- Reset the test with a new piece of text
- Challenges you with fresh content for varied practice

### 📈 Performance Statistics
- View your typing scores over time
- Access detailed statistics by clicking "Show Scores"

## How to Use

1. Open the application in your web browser
2. Start typing the displayed text to begin the test
3. Monitor your performance with the live accuracy tracker
4. Use the "Restart" button to practice on the same text again
5. Click "Reset" to get a new piece of text
6. View your progress by clicking "Show Scores"
